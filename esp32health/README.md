# ESP32Health

Home Assistant-app til Seeed MR60BHA2 og MR60FDA2 via ESPHome. Viser radar-estimeret puls og vejrtrækning, tilstedeværelse, afstand og faldsignal samt historik fra Recorder.

Installér, start, og vælg **Åbn web-UI**. Forbindelsen til Home Assistant er automatisk, og enhedsopsætningen gemmes i appen. Kan vises i sidepanelet. Læs fanen **Dokumentation** for opsætning og målebetingelser.
